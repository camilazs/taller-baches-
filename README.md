# taller-baches-

## Aplicación de captura visual y detección de baches

El proyecto está en [baches](baches). Para ejecutarlo: `cd baches` y `npm.cmd start`; abrir http://127.0.0.1:3102. Requiere Node.js 22.9 o superior.

Consulta [la entrega](baches/ENTREGA.md) y [el estado de publicación](baches/PUBLICACION.md). La detección real requiere configurar una clave privada del proveedor y aportar imágenes originales; no se incluyen resultados simulados como reales.
